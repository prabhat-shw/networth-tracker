## The short version

This app tracks **everything a household owns and owes**, splits it by **who owns what
share**, tags it to **what the money is for**, and does all of that **without any server
ever being able to read your data**.

Deeper reference material lives one level up: [`docs/PLAN.md`](../PLAN.md) (the full plan),
[`docs/ARCHITECTURE.md`](../ARCHITECTURE.md), [`docs/SECURITY.md`](../SECURITY.md),
[`docs/UX.md`](../UX.md), and [`docs/decisions/`](../decisions/) for the reasoning behind
every choice.
